- [ ] 顶行:重新框选 / 全页 / 取消;遮罩外点按或 ✕ 退出后书写立即恢复

## 4. 真实厂商手测(至少一家,GLM/DeepSeek/Kimi/MiniMax/MiMo/Qwen/OpenAI/Claude/Grok/Gemini/OpenRouter 任选)
