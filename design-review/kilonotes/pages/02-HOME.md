# 首页、创建与笔记本管理

| 页面 ID | 入口 | 实测内容与按钮 |
|---|---|---|
| P009_create_notebook | 首页 → 创建 | 创建卡片右侧生长菜单：笔记本、导入、图片、拍照。该菜单无有效语义 XML，已以截图为准。 |
| P010_create_notebook_form | P009 → 笔记本 | 独立创建页，首次覆盖横竖屏提示；按钮“知道了”。 |
| P011_create_notebook_form | P010 → 知道了 | 左上横竖屏切换、右上关闭、标题“无标题的笔记本”、直接创建、封面/内页预览，下方封面分类与模板。38 个语义控件。 |
| P012_create_page_templates | P011 → 内页预览 | 内页选择：纸色、空白纸、点阵纸、方格纸、横线纸、英文纸、田字格纸；下方付费模板。 |
| P013_create_dot_selected | P012 → 点阵纸 | 点阵纸选中，创建按钮变为“确定创建”。 |
| P046_notebook_actions | 首页 → 测试本更多 | 居中卡片菜单：名称编辑（自动唤起键盘）、编辑、删除、移动、7 色标签。未执行删除。 |
| P047_settings | 首页 → 设置 | 右侧设置抽屉，首次有“关于我们”提示。 |
| P048_settings | P047 → 知道了 | 我的备份空间、AI 积分、数据备份、自动备份、合并笔记、视频教程、兑换码、图片性能优化、关于、反馈、隐私等。 |
| P049_settings_lower | 设置 → 向下滚动 | 另见个人信息收集清单、第三方信息共享清单、注销账号。未点击注销。 |
| P050_auto_backup | 设置 → 自动备份 | 中央“请选择备份服务”：百度网盘、Dropbox、GoogleDrive；未连接账号。 |
| P054_import | 首页 → 导入 | 文件管理器“最近”：大型文件、本周筛选，搜索、更多、网格切换；名称/类型/大小/修改时间列，空状态“无任何文件”。 |
| P055_import_locations | P054 → 汉堡按钮 | 左侧“打开文档”位置：最近、文档、下载、本机存储。 |
| P056_vip | 首页 → VIP | 两次按准确 bounds 点击均停留首页；当前环境未展示会员页，标记无可见响应，不推测原因。 |
| P057_home_sort | 首页 → 排序 | 右侧排序菜单：种类、名称、修改时间（当前）、上次打开、标签。 |

## 关键位置观察

- 首页主内容使用卡片网格，新建卡片固定在首个位置。
- 创建类型菜单从首张卡片右侧生长；迁移到 MilkNote 时改为中央动作面板。
- 笔记本卡片更多菜单已经居中，但重命名与键盘同屏；MilkNote 中央面板需要 IME 避让。
- 导入是完整文档选择界面，不是简单相册入口。
