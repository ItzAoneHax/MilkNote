# 编辑页面板、导出与 AI

| 页面 ID | 入口 | 实测内容与按钮 |
|---|---|---|
| P021_image_tool | 编辑页 → 图片 | 先显示应用内“存储空间/照片权限说明”，按钮“知道了”。 |
| P022_photo_permission | P021 → 知道了 | 系统照片权限：允许有限访问、全部允许、不允许。 |
| P023_image_picker | P022 → 全部允许 | 返回编辑页，未自动打开选择器；需要再次点击图片。 |
| P024_image_picker | 再次点击图片 | 中央大弹窗：照片、相簿、取消；空相册无内容。 |
| P033_record_permission | 编辑页 → 录音 | 首先请求通知权限。 |
| P034_record_mic_permission | 拒绝通知 | 继续请求录音权限：使用应用时允许、仅限这一次、不允许。选择不允许，未进入录音界面。 |
| P035_video_tool | 编辑页 → 学习视频 | 中央“学习视频”：照片/文件来源、现在添加、关闭；文案说明可自由缩放移动、倍速、截屏。未添加视频。 |
| P036_ai | 编辑页 → AI | 右侧“阅读助手”抽屉：深度思考、解题专家、输入框、加号、发送；未登录状态也可看到空会话。 |
| P037_ai_attach | AI → 加号 | 输入区下方就地展开“图片 / 相机”，加号变为关闭。 |
| P038_material_library | 编辑页 → 素材 | 右侧素材抽屉：我的素材、素材工具、分类、素材网格和下载按钮。 |
| P039_new_page | 编辑页 → 新建页 | 右侧页面配置：替换页面、页面之前、页面之后、最后一页；纸张颜色与类型、模板。 |
| P040_more_menu | 编辑页 → 更多 | 右侧更多菜单，首次覆盖超级白板提示。 |
| P041_more_menu | P040 → 知道了 | 导出、分享、笔记本名称、纸张留白调整、自定义工具栏、超级白板、参考线、单指双击缩放、触控笔设置。 |
| P042_export | 更多 → 导出 | 导出格式 PDF/JPG/千本笔记 ZIP；文件名、页面范围、导出文件。 |
| P043_export_page_range | 导出 → 页面范围 | 页面缩略图多选，“已选2/2”“取消全选”；第 1 页为封面，第 2 页为内容页。 |
| P044_custom_toolbar | 更多 → 自定义工具栏 | 中央面板：取消、确定、显示工具、删除和拖拽排序；画笔、荧光笔、橡皮擦、套索、图片、文本、涂鸦笔、图形、摘取、胶带。 |
| P045_custom_toolbar_lower | 自定义 → 滚动 | 另有阅读工具、激光笔、卡片、贴纸；隐藏工具、快速访问隐藏工具开关、恢复默认。 |

## 中央面板改造对应

| 千本笔记原实现 | MilkNote 统一方向 |
|---|---|
| 笔、图形、颜色从按钮向下生长 | 中央调整面板，保留预览与当前状态 |
| 新建页右侧配置 | 中央页面面板，位置 + 纸张 + 模板，明确确认动作 |
| 更多右侧长菜单 | 中央动作/设置面板，分组滚动 |
| 导出二级生长面板 | 中央导出面板，格式 + 文件名 + 页面范围 |
| AI 加号就地展开 | 中央附件面板，图片/相机与现有页/整章附件融合 |
| 已经是中央的图片、视频、自定义工具栏 | 保持中央，复用 MilkNote 统一表面和关闭行为 |
