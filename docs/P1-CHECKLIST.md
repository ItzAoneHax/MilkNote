# 真机 P1 验证操作清单

> **用途**:按 [PEN-ADAPTATION](./PEN-ADAPTATION.md) §7 完成按键/压感/拦截的真机实测,回填文档升版 A3。
> - 设备:**主力机 小米平板 8 Pro(HyperOS 3.0+ / Android 16)+ 焦点触控笔(一代)**;**备用机 小米平板 7 Pro** —— **两台各做一遍**,结果可能不同。
> - 构建:`./gradlew :app:assembleDebug` → `app/build/outputs/apk/debug/app-debug.apk`(`adb install -r`)。
> - 时间:每台约 20 分钟。

---

## 0. 准备

1. 笔磁吸到平板顶部充电位,确认系统弹出笔电量/配对提示(系统层面已连)。
2. 安装 MilkNote,启动。首次会弹「附近的设备」权限弹窗 → **允许**(笔电量 GATT 需要;拒绝则顶栏恒 `--%`,可去 书架 ⚙ 设置 → 笔电量 → 授予权限)。
3. 顶栏应出现 `🪶 --%` 或真实电量;**若显示真实电量,记录数值与是否合理**(可能误连其它 LE 设备,P2 修正名单)。
4. 进入任一笔记本书写页;**长按顶栏 🪶 胶囊** → 笔诊断面板。
5. 用笔在纸面**写 30 秒**(任意涂写)→ 诊断面板「压力 30s」出现 min/p50/max 条 → **截图或导出留档**(导出按钮 → 文档/MilkNote/*.txt,含设备信息+全部事件流水)。

## 1. P1 实体键投递(核心:逐键 × 4 种操作)

在书写页打开诊断面板,依次做下表每个动作,每种之间**清空流水**方便对照。看流水里的 `BTN`(button 位)与 `KEY`(keyCode)行、`TRIGGER`(应用判定结果)行,逐格回填:

| 动作 | 主键(书写键) | 副键(截图键) | 焦点键(笔顶) |
|---|---|---|---|
| 悬空单击 | 流水:____ | 流水:____ | 流水:____ |
| 悬空双击 | | | |
| 悬空长按 1s | (系统画板是否弹出?) | (系统截图是否触发?) | (画笔图标/激光笔?) |
| 笔尖触屏时按一下 | | | — |
| 按住键 + 落笔书写 | TRIGGER 应为「主键按住书写→套索选择」→ 圈选生效? | TRIGGER 应为「副键按住书写→临时橡皮」→ 擦除生效? | — |
| 悬停时按键(笔尖离屏 5mm) | KEY 行的 keyCode=? | keyCode=? | keyCode=? |

**重点关注**:
- 接触时是 `BUTTON_STYLUS_PRIMARY/SECONDARY` 位还是非标准位(十六进制 btn=0x?);
- 悬停时 `dispatchKeyEvent` 收到的真实 keyCode(标准应为 `KEYCODE_STYLUS_BUTTON_PRIMARY/SECONDARY`,API 34+;若是厂商自定义码,记下数字);
- **焦点键是否/如何到达应用**(完全可能被系统吃掉——这正是 P1 要回答的);
- 「按住+书写」的套索/临时橡皮是否按预期生效(应用内已实现,失效说明该通路被拦截)。

## 2. P2 压感

1. 蓝牙已连:书写 30s → 记录 min/p50/max。
2. 系统蓝牙**断开**(笔保持可用则书写不受影响)再写 30s → 对比:压力是否仍可用?值域差异?
3. 极轻笔尖搭纸(0g 力度):min 是否≈0.02 死区附近。
4. 回填 PEN-ADAPTATION §3.4/§6 蓝牙降级条件。

## 3. P3 系统拦截边界

MilkNote 前台时逐一执行,记录「系统行为」vs「应用流水」:

| 手势 | 预期系统行为 | 实测 |
|---|---|---|
| 副键长按 + 轻点屏幕 | 系统截图 | |
| 主键长按 + 触屏 | 唤起小米画板 | |
| 焦点键双击 | 清屏 | |
| 焦点键长按 | 虚拟激光笔 | |

→ 回填 §1.1/§4.3 冲突清单(确认「按键仅在书写时生效」文案是否需调整)。

## 4. 新功能真机体验(应用侧)

- [ ] 套索:书写页工具栏第 5 个图标(或主键单击默认动作)→ 圈一圈 → 「已选 N 笔」→ 拖动 / 删除 / 撤销。
- [ ] 临时橡皮:按住副键书写 = 整笔划擦除。
- [ ] 改绑:书架 ⚙ → 笔与手势 → 任意改绑 + 恢复默认,验证生效。
- [ ] 压感三档:设置 → 书写 → 柔和/标准/灵敏,写「撇」对比笔锋。
- [ ] 前置缓冲出墨:设置 → 书写 → 打开开关 → 写字感受延迟(状态条出现 `front-buffer` 标记)。**此项性能以真机为准**,若有闪烁/残影立即关掉并记录现象。
- [ ] 悬停光标:笔悬停纸上出现圆环。
- [ ] 预测尾巴:快速甩笔,笔迹是否追手(swiftshader 模拟器无法验证此项)。

## 5. 回填方式

每台机器结束前:诊断面板 → **导出**(落盘 文档/MilkNote/*.txt,含设备信息+直方图+全部事件流水),连同上面表格的空格一起交给开发者,回填 PEN-ADAPTATION §4.1/§4.4/§7 后升版 A3。
