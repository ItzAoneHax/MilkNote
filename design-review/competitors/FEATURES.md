## 对 MilkNote 的直接参考点

1. **首启零门槛**（Obsidian / SpeedyNote / StarNote 共同点）：无账号即可完整使用，账号只服务于同步；StarNote 用可关闭的软提示引导注册，而不是阻断。
2. **书架 vs 标签页**：StarNote 的「封面卡片 + 左侧分类树（未分类/未标签/回收站/文件夹/标签）」与千本笔记同构；Obsidian 则彻底浏览器化。MilkNote 的书架更接近前者。
3. **可拖拽工具栏**（StarNote）：单行工具栏可吸附到四边；SpeedyNote 用「钢笔展开 3 色 + 3 粗细预设，再点编辑」减少面板层级。两者都比固定底部工具栏更节省纵向空间。
4. **双开**（StarNote）：同一画布左右分屏两本笔记、共用工具栏，是平板端差异化能力。
5. **保存语义**（SpeedyNote）：不显式保存即丢弃且无提示，是反面案例；Obsidian 与 StarNote 均自动保存。
6. **OCR / 录音 / 模板 / 留白**：StarNote 把「页面留白调整」「更换新增页模版」「导入音频」「计时器」放在更多菜单，作为低频但高价值的边缘功能。
