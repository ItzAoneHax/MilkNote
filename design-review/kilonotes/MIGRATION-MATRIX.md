## 7. 验证边界与受阻项

- 完整命令 `./gradlew.bat test :app:assembleDebug` 通过；具体测试与模拟器证据见 `VERIFICATION.md`。
- 模拟器没有真实手写笔；压感、笔键、防误触仍需在小米平板与焦点笔上复验。
- 拍照入口已发起系统 `IMAGE_CAPTURE`，但当前模拟器没有前/后摄像头，系统相机自身崩溃，故只验证入口，未验证成像。
- 媒体播放依赖系统 codec；视频整文件复制于 IO 线程，无转码。导出 PDF/图片只含静态媒体占位，不包含视频画面或音频波形。
- 页面“替换”仍未实现；自动云备份、网盘、账号、会员、竞品商店和千本笔记 ZIP 均不伪装支持。
- 卡片库为应用级本地数据，不包含在单本 `.milk.zip` 中；卡片中的来源 ID 仅作来源记录。
