# 牛奶笔记第二代 · MilkNote Gen 2 设计说明

> **视觉原则**：自然、克制、零冗余说明。让元素的比例、位置与形态自己说话，不做 AI 模板化的彩色卡片嵌套与渐变光效。  
> **产出目录**：`design-review/gen2/`

## 1. 视觉与配色重构

- **自然色阶**：放弃人工感米黄+深青+霓虹渐变，采用极简纸墨中性色体系——
  - 浅色：`#FFFFFF` 纯白主面与纸张 · `#F6F6F8` 中性浅灰平齐侧栏 · `#EFEFF2` 柔和画布底 · `#18191B` 墨黑主字 · `#2563EB` 单一钢笔蓝强调色 · `#D94436` 朱砂批注红。
  - 深色：`#16171A` 石墨主面 · `#111214` 静夜侧栏 · `#0D0E10` 画布底 · `#5B92FF` 高可读蓝；纸面封面/缩略图恒保持亮色纸面，笔诊断终端恒保持深色。
- **形态即说明**：
  - 书架取消多层外框卡片与成排标签徽章，采用 **3:4 竖向实体书本比例**，以书脊色带、右上红色丝带书签（置顶）、右上折角与纸面右下角 `PDF` / `∞` 淡印直接传达状态；虚线空位只放一枚居中 `+`。
  - 书写页取消两行全宽工具条与发光文字胶囊，采用 **44dp 单行多标签顶栏 + 轻盈单行悬浮笔匣**（粗细用真实的细/中/粗线条表达，右侧智匣默认收起，让纸面占据绝大部分视野）。
  - 预览网页直接全屏展开原生应用，去掉顶部厚重控制台与按钮列表，仅在右下角保留极轻的 `应用 / 图标 / 明暗` 悬浮切换钮。

## 2. 竞品实测吸收（基于 `design-review/competitors/`）

- **StarNote**：左侧分类树 + 回收站、实物感竖向封面、多标签与左右双开分屏、笔盒收藏与笔画稳定、右侧留白。舍弃免费配额横幅与 17 图标平铺。
- **SpeedyNote**：单行笔匣内联常用色/粗细、手写与 Markdown 伴随笔记并排、分页/无边画布可选、悬浮防误触 500ms 延迟。坚持全自动保存，避免未保存丢失。
- **Obsidian**：顶栏多标签、右侧关联/双链切换、设置检索、零账号本地优先。
- **OneNote / Gemini Notebook / Goodnotes**：实测止于强制登录墙，强化 MilkNote 本地零账号立身之本。

## 3. 全新应用图标（`icons/`）

- **方案 A（主推）· 奶滴笔锋**（`icon-a-nib-drop.svg` + Android Adaptive XML）：干净钢笔蓝渐变底 + 奶白水滴轮廓，内部笔缝与气孔构成钢笔尖，右上一点微光星点呼应视觉 Agent。
- **方案 B · 折页手笺**（`icon-b-folded-folio.svg`）：素白纸页 + 钢笔蓝书脊 + 朱砂折角 + 压感墨迹 `M`。
- **方案 C · 墨砚奶滴**（`icon-c-ink-seal.svg`）：深石墨底 + 素白奶滴笔锋 + 蓝色微光点。
